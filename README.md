## How to start
### 내 프로젝트 시작하기:
```bash
$ uv init_project.py --name my_manim
```


### Manim impl. 기본기:
1. 클래스가 하나의 영상입니다
2. `manim main.py <class_name>` 실행 시 <class_name>.construct()를 실행합니다
3. 생성된 영상은 `videos/`에 저장됩니다
